# Domain docs

Read `CONTEXT.md` before exploring the project.

Read ADRs in `docs/adr/` that affect the work. Missing context files and ADR directories require no warning. The domain-modeling skill creates them when terminology or decisions need recording.

Use terms defined in `CONTEXT.md`. Flag proposals that conflict with an existing ADR.

## Layout

This repository uses a single-context layout:

- `CONTEXT.md` records the combat console domain model.
- `docs/adr/` records architectural decisions.
